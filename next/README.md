# Ivoire Pool — version React

Version finale de la landing page, en **Next.js 16** (App Router), **React 19** et **Tailwind CSS 4**.

## Démarrer

```bash
npm install
npm run dev    # http://localhost:3000
npm run build
npm run start
```

## Structure

```
app/
layouts/
sections/landing/  une section par fichier (hero, about, services…)
components/        header, footer, menu mobile, icônes
types/             types partagés
assets/css/        tokens Tailwind
public/            assets statiques
```
